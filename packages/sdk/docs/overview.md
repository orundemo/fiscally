# sdk

Runtime-agnostic TypeScript SDK for the Fiscally control plane API

A shared package of the fiscally workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the Fiscally control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the Fiscally web console (per-environment, Workers + Static Assets)
